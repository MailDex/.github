## Inside MailDex

MailDex is a local Windows mail search app with a named dex desk, a short search list, and a clear last handoff. It does not try to replace the rest of the PC. It sits beside mail files you already keep and holds only the index that is open now.
The layout stays small on purpose: one desk, one list, one path back. Extra stores wait for their own title. MailDex starts with a local profile and does not need a complex account system.
